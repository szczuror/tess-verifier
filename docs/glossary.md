# Glossary

## Concepts

| Concept | Definition |
|---|---|
| Target Star | A star observed by a telescope and checked for signs of orbiting planets. |
| Transit | A regular dip in a star's brightness caused by an object passing in front of it. |
| Light Curve | A record of how a star's brightness changes over time. |
| Candidate | A transit signal around a target star that may be a planet, but has not been confirmed yet. |
| False Positive | A transit-like signal caused by another phenomenon rather than a planet. |
| Eclipsing Binary | Two stars orbiting and periodically blocking each other, often mimicking a planetary transit. |
| Blending (Crowding) | A situation where light from a nearby star mixes with the target star in the same telescope area, making it unclear which star is dimming. |
| Verification Test | A check used to determine whether a candidate's signal comes from a planet or a false positive. |
| Disposition | The current verification status of a candidate, such as planet candidate, confirmed planet, or false positive. |
| TOI | TESS Object of Interest: a candidate flagged by the TESS team, identified by a number such as TOI-1234.01. This is the candidate's number the user gives the agent. |
